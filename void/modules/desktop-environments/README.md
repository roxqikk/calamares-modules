# Desktop environment modules (Void) - list

This directory contains ready-to-edit Calamares module templates for several desktop environments.

Available options (each has module.conf and an install script):
- hyprland
- kde-plasma
- i3wm
- niri
- gnome
- budgie
- xfce4
- lxqt
- lxde
- sway

Each install script is a Void-specific template using xbps. Review and adapt package names and extra steps (e.g., greeter, display manager, compositor, graphic drivers) before use.
