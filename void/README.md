# Void Linux Calamares modules

This directory contains example Calamares modules tailored for Void Linux. Each module is a small example showing how you can structure module configuration and optional helper scripts.

Available example modules:

- user-creation — example to create system user(s)
- desktop-setup — example to install and configure a desktop environment
- package-installation — example to install packages using xbps
- post-install — example post-install script (final steps)
- partition-presets — example partitioning presets
- locale-keyboard — example locale and keyboard module
- branding — example of branding assets and config
- service-enable — example to enable/disable systemd services

mirrors/: see repository-wide mirrors information and examples.

Note: these modules are templates and placeholders. Review and adapt before using them in a real installer.
